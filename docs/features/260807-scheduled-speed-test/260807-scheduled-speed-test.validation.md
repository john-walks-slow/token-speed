# 定期测速功能 用户验证

## 验证说明

- 验证对象：定期测速 Tab（创建/管理定时任务、自动执行、历史标记）
- 环境/前置条件：
  - 后端已启动（含 lifespan 调度器）
  - 至少 1 个可用服务商 + 已检测模型
  - 浏览器打开前端
