# 测速指标口径 Canonical 化 用户验证

## 验证说明

- 验证对象：tps 重定义为「回答阶段生成速度」、统计 median 化、reasoning 多厂商兼容、thinking_ms 新增
- 环境/前置条件：需要至少一个真实 OpenAI-compatible 端点（含 reasoning 模型的更好）；后端与前端能正常启动
