# 260807-desktop-app 用户验证

## 验证说明

- 验证对象：Token Speed 桌面版（pywebview 窗口 + pystray 托盘 + 开机自启）功能
- 环境/前置条件：
  - Windows 10/11，已构建 `dist/TokenSpeed/TokenSpeed.exe`
  - 已配置至少一个 provider（含 API key），用于验证定时测速后台运行
  - 开发环境 python 可用（用于验证保留的服务器部署能力）
